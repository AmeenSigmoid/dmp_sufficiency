# DMP — Coverage (Data Sufficiency)

Prototype UI for the Data Product Marketplace **Coverage** page:
- **View by Use Case** — Data Sufficiency Summary (heat map) + drill-in Detail (granularity drivers, expected granularity).
- **Reimagined Flow** — KPI overview, searchable use-case list, per-use-case diagnostic.

Static single-page app — `index.html` (HTML + CSS + JS inline). Deployed on Vercel.
